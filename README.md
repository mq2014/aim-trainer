# 练枪 · 瞄准训练

一个网页射击训练小游戏，用来练瞄准、热身、测反应。三个训练区同屏并存、各自独立计分，一局 60 秒。

> 作品仍在迭代中。

## 三个训练区

| 区域 | 规则 |
|---|---|
| **固定靶 Fixed** | 靶子固定不动，点中 +10 分 |
| **移动靶 Moving** | 圆点沿随机轨迹平滑移动，考验追枪 |
| **反应力 Reaction** | 目标出现后限时 **1.0 秒**；剩余 1.0s 点中得 100 分，每慢 0.1s 减 10 分 |

## 计分与评级

- 一局 60 秒，倒计时 ≤10 秒时转红脉冲提示，也可手动提前结束
- 三区独立计分 + 总得分
- **命中率** = 命中 / (命中 + 失误)
- 记录**平均反应时间**（毫秒）
- 评级：

| 评级 | 条件 |
|---|---|
| S+ 枪王神射手 | 总分 ≥ 400 且命中率 ≥ 85% |
| S | 总分 ≥ 250 且命中率 ≥ 75% |
| A | 总分 ≥ 150 |
| B | 总分 ≥ 80 |
| C | 起步 |

## 可调参数

参数面板可调整，设置保存在浏览器 `localStorage`：

| 键 | 默认值 |
|---|---|
| `aim_trainer_settings` | 靶子大小 24px、靶心色 `#FF2A2A`、准心样式 `cross`、音量 0.3 |
| `aim_trainer_high_score` | 历史最高分 |

## 视觉

战术 HUD 风格：网格底纹、自定义准心光标、等宽字体、暗黑底色 `#0c0c0a` 配警示红 `#FF2A2A` 与青色点缀，不是休闲小游戏的卡通画风。

## 运行

因为入口用了 ES module，**不能直接双击 `index.html` 用 `file://` 打开**（浏览器会拦截 module 脚本）。请起一个静态服务：

```bash
python -m http.server 8000
# 然后打开 http://localhost:8000
```

或把这个目录托管到任意静态托管服务（GitHub Pages / Cloudflare Pages 均可）。
