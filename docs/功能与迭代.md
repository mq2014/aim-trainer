# 练枪：功能细节与版本演进

## 功能细节（从线上打包文件解析）

### 三个区域

- **固定靶**：圆形靶心静态摆放，点击命中 +10 分，未命中记一次失误
- **移动靶**：靶点按随机目标点做平滑插值移动，需要预判与追枪
- **反应力**：目标闪现后开始 1.0 秒倒计时，越快点中得分越高。计分从剩余时间换算：剩 1.0s → 100 分，每减少 0.1s 扣 10 分；超时未点中不计命中

### 一局的节奏

1. 进入后三个区域同时可用
2. 全局 60 秒倒计时，剩余 ≤10 秒时数字变红并脉冲
3. 可随时手动结束本局
4. 结算展示：三区各自得分、总得分、命中率、平均反应时间、评级
5. 最高分写入 `localStorage`

### 参数面板

- 靶子大小（默认 24px）
- 靶心颜色（默认 `#FF2A2A`）
- 准心样式（默认 `cross`）
- 音效音量（默认 0.3）

设置序列化在 `aim_trainer_settings`，最高分在 `aim_trainer_high_score`。

### 评级阈值

| 评级 | 总分 | 命中率 |
|---|---|---|
| S+（枪王神射手） | ≥ 400 | ≥ 85% |
| S | ≥ 250 | ≥ 75% |
| A | ≥ 150 | — |
| B | ≥ 80 | — |
| C | 其他 | — |

## 版本演进（2026-08-13，一天 6 版）

1. **首版**：搭出三区瞄准训练的基本形态
2. **修反应力原点只闪一次**：目标刷新逻辑改为持续出现
3. **改 1 秒限时**：反应力区从无限等待改为 1.0 秒窗口
4. **重写计分规则**：由固定分改为「按剩余时间递减」的反应力计分
5. **统一一局 60 秒**：三区共用全局计时，加倒计时告警与手动结束
6. **支线副本**：另开「红狼 + 威龙导师」版本，面向小学生，未发布

## 当前可优化方向

- 小屏 / 触屏适配（准心与靶子尺寸在手机上偏小）
- 移动靶难度分级（速度、轨迹突变）
- 多人排行榜与历史曲线（目前只有本地最高分）
- 打包产物无法直接二次开发，若要继续加功能，建议按上述规则重写为源码工程
